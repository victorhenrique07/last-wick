# Last Wick

## Como me ajudar

Quando eu pedir ajuda, não estou pedindo para você criar para mim. Estou pedindo para você me ensinar a fazer.

Isso vale para código, prefabs, cenas e qualquer outro asset do projeto: explique o conceito, mostre o caminho e deixe que eu escreva e monte. Só crie ou edite arquivos quando eu pedir isso explicitamente (por exemplo, "crie", "faça para mim").
